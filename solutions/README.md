# Reference solutions

These exist so the course can test itself (`R2R_SOLUTIONS=1 pytest`) and
so instructors can grade. The course's CI runs the full examiner suite
against these files; every number quoted in a module README was produced
by them.

## Before you open a file in here

The modules were built so that each one ends with a wall, and the next
begins with a rescue. The struggle at the wall *is the course* — the
README narratives, the measured failures, the tests, all of it exists to
set up roughly eleven moments of "wait, I built that?", and those
moments only fire for code that you fought for.

Copying a solution doesn't skip the work. It skips the course.

If you're stuck, in order:

1. Reread the module README — the answer's shape is always described.
2. Read the failing test. Tests are specifications in disguise.
3. Ask someone (or an AI) a *question* about the concept. Not for the file.
4. Sleep on it. Bucket brigades run overnight.

Then, *after* your version is green, by all means read the reference and
compare. That comparison is genuinely instructive — it's the only use of
this folder that adds anything to you.
